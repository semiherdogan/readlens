SECTION 1: PROJE TANIMI

Proje adı geçici olarak CleanWeb olabilir.

CleanWeb, local çalışan ve AI modellerine web sayfalarının ham HTML veya DOM çıktısını vermek yerine yalnızca okunabilir ana içeriği sağlayan bir content gateway olacaktır.

Ana fikir:

AI bir URL verir.
CleanWeb sayfayı açar.
JavaScript gerekiyorsa Lightpanda ile render eder.
Ana içerik Mozilla Readability benzeri bir extractor ile bulunur.
Navigasyon, footer, cookie popup, sidebar, reklam ve benzeri gereksiz içerikler temizlenir.
AI'a yalnızca temiz ve yapılandırılmış içerik döndürülür.

Projenin amacı browser automation yapmak değil, web içeriğini LLM'ler için okunabilir hale getirmektir.

Kısa değer önerisi:

A local web reader for AI agents that returns content, not webpages.

SECTION 5: CORE PIPELINE

İşlem sırası:

URL alınır.

URL normalize edilir.

Güvenlik kontrolleri yapılır.

Cache kontrol edilir.

Cache varsa kayıt döndürülür.

Cache yoksa sayfa fetch edilir.

İlk olarak normal HTTP fetch denenebilir.

HTTP sonucunda yeterli içerik varsa browser açılmaz.

Sayfa JavaScript gerektiriyorsa Lightpanda kullanılır.

Lightpanda JavaScript çalıştırılmış DOM'u üretir.

DOM ana içerik extractor'a gönderilir.

İlk extractor Mozilla Readability olur.

Readability yeterli içerik çıkarırsa sonuç cleaner'a gönderilir.

Readability başarısız olursa fallback extractor kullanılır.

Cleaner gereksiz parçaları kaldırır.

Metin normalize edilir.

Metadata çıkarılır.

İçerik uzunluğu kontrol edilir.

Sonuç structured output olarak AI'a gönderilir.


----

SECTION 6: RENDER STRATEJİSİ

Render seçenekleri:

auto
always
never

auto:

Önce normal HTTP fetch yapılır.
Yeterli içerik bulunursa direkt extraction yapılır.
İçerik yetersizse Lightpanda açılır.

always:

Her zaman Lightpanda kullanılır.

never:

Browser kullanılmaz.
Yalnızca HTTP üzerinden alınan HTML işlenir.

Default değer auto olmalıdır.

Bu yaklaşım statik web sitelerinde gereksiz browser maliyetini azaltır.

SECTION 8: CONTENT EXTRACTION

Birinci extraction yöntemi Mozilla Readability olmalıdır.

Readability'den alınabilecek alanlar:

dialog
form
button

Temizleme yalnızca kelime blacklist'i ile yapılmamalıdır.

Bu nedenle mümkün olduğunca DOM yapısı, element rolü, class isimleri, text density ve tekrar oranları kullanılmalıdır.

SECTION 25: SON HEDEF

Son kullanıcı deneyimi mümkün olduğunca basit olmalıdır.

Kurulum:

cleanweb install

Çalıştırma:

cleanweb mcp

AI configuration:

command = cleanweb
args = mcp

Bundan sonra AI tek bir tool görür:

read_page

Kullanıcı bir URL gönderdiğinde AI browser kullanmak yerine CleanWeb'i kullanır.

CleanWeb sayfayı render eder, ana içeriği bulur, temizler ve AI için minimum gürültülü veri üretir.

Projenin temel prensibi:

The AI should read the page, not browse the DOM.
